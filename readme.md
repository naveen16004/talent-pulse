# 🎯 TalentPulse

> An AI-powered candidate evaluation engine and talent intelligence system that parses resumes, executes schema-validated gap analyses against job descriptions, and renders actionable screening reports.

## 🛠 Tech Stack
- **Backend:** Python 3.11, FastAPI, Pydantic v2
- **Intelligence:** OpenAI Structured Outputs (`gpt-4o-mini`), PyPDF
- **Dashboard:** Streamlit
- **DevOps:** Docker, GitHub Actions CI
